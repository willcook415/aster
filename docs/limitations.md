# Limitations

## Current Limitations

Aster currently contains only the initial workspace scaffold. The order book, matching engine, event log, and replay system are not implemented yet.

## Explicit Non-Goals For MVP

Dashboards, WebSocket feeds, real market data, trading bots, AI features, FIX protocol, database persistence, multi-symbol exchange routing, and user account systems are out of scope until the core engine is credible.
